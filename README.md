1. Introduction
The purpose of this project was to create a simple Morse code transceiver. Device that will receive morse code of 1 word from button in transmitter mode, decode and show it on LCD screen, and after that transmit that morse code to the receiver. Transceiver in receiver mode also decodes and shows decoded word on the LCD. Mode is controlled by switch, morse code is entered via button. Buzzer and LED provides feedback, LCD shows decoded word and last is NRF24L01 module that handles wireless communication.

2. Materials and Methods
2x Breadboard
2x Arduino Uno 
2x NRF2401+ (Module for transmitting/receiving data)
2x I2C LCD1602 (SunFounder Sensor Kit V2.0) (Display for output)
2x Switch (for changing modes)
2x Buttons (for input data)
2x Active Buzzer 
2x LED
Cardboard
Battery 9V
Resistors 330 Ohm (for LED) and 200 Ohm (for Buzzer)
jump Wires
